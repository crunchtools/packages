crunchtools packages

Signed dnf and apt repositories for crunchtools command line tools, built from their GitHub releases.

Fedora, RHEL 8/9/10 and rebuilds, Amazon Linux 2023

sudo curl -fsSLo /etc/yum.repos.d/crunchtools.repo https://crunchtools.github.io/packages/rpm/crunchtools.repo
sudo dnf install petit

SUSE Linux Enterprise 15 SP7 and 16, openSUSE

sudo zypper addrepo https://crunchtools.github.io/packages/rpm/crunchtools.repo
sudo zypper install petit

Debian 12 and 13, Ubuntu 24.04 and 26.04

sudo install -d /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/crunchtools.asc https://crunchtools.github.io/packages/crunchtools.asc
sudo curl -fsSLo /etc/apt/sources.list.d/crunchtools.sources https://crunchtools.github.io/packages/deb/crunchtools.sources
sudo apt update && sudo apt install petit
